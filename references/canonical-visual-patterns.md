# Canonical Visual Patterns

本文件记录已经由用户确认的 Clear 最终样板。它们用于校准抽象规则，不保存样板中的私人数据。

## 1. 样板优先级

当通用规则与已确认样板发生出入时：

1. 当前对话中用户最新明确确认的样板
2. 总档案馆中的最新版邮箱 / 消费支出规划
3. 本文件提炼出的视觉规律
4. `SKILL.md` 的通用建议

只继承最终视觉规律，不复制旧 HTML 中为兼容历史版本追加的补丁结构。

## 2. 邮箱样板

稳定规律：

- 页面背景为 `#fbfbfd → #f3f4f7` 的冷白浅灰
- Header、Section 为接近白色的半透明中性面
- 账号 Card 为白色或 `#fff → #fcfcfd` 的极轻渐变
- 平台色仅用于 2–3px 顶部线、小圆点、tag、极淡 edge / wash
- Outlook / Gmail / QQ / Apple / 阿里云 / 新浪使用不同的低饱和平台色
- 同平台重复账号可放在统一列表面板里，用分隔线替代卡片套卡片
- 主账号用字重和 Core 阴影突出；历史账号退灰

结论：邮箱样板是“中性页面 + 多个小范围平台色”，不是蓝色主题页。

## 3. 消费支出规划样板

稳定规律：

- 页面主体仍是冷白浅灰和白色容器
- 虚拟消费使用灰蓝紫 `#6676a8`
- 住房消费使用暖沙棕 `#b28a5d`
- 账户用途使用青灰绿 `#5f8b84`
- 每月定存使用香槟金 `#a9854f`
- 固定总额 / 提醒使用中性深灰 `#4e5968`
- summary（汇总）以白卡 + 3px 色线 + 极淡 edge 表达类别
- section 使用白底，颜色放在顶部线、金额 pill、小圆点或进度条
- 染色后的嵌套背景只允许非常淡，并避免父子同时染色

结论：消费规划样板通过多组克制语义色帮助扫描，但页面的大面积仍然是中性的。

## 4. 映射到日常任务 / 年度计划

建议映射：

| 分类 | 语义色 | 主要载体 |
|---|---|---|
| 学习 | 雾蓝 `#597fb4` | 顶部线、圆点、完成勾选 |
| 整理 | 青灰绿 `#5f8b84` | 顶部线、圆点、完成勾选 |
| 创作 | 灰紫 `#77738f` | 顶部线、圆点、完成勾选 |
| 积累 | 暖沙金 `#a9854f` | 顶部线、圆点、完成勾选 |
| 日记 / 历史 | 中性灰 `#657080` | 小标签、分隔信息 |

今日重点是优先级，不等于完成状态。它使用中性白色面板和小型编号，不另造大面积蓝色区块。

年度计划默认折叠。父容器保持中性，展开后的目标按类别使用小范围语义色，避免整组蓝卡。

## 5. 眯眼测试

缩小页面或眯眼查看：

- 应先看到中性的整体骨架
- 再看到少量分散的分类色线索
- 不应首先看到一大片蓝色、紫色或金色
- 色彩消失后，分组和字重仍应成立
