# Content Patterns

## 邮箱档案

### 分组

先按平台，再在平台内部区分主账号 / 常用 / 备用 / 历史。

### 视觉

- 平台色只做顶部线、小圆点、tag、极淡 edge
- 主邮箱用 Core 或更高字重
- 普通邮箱用 Normal
- 历史邮箱退灰并降低阴影
- 同平台账号保持同一色系

### 不要

- 每个邮箱随机一种颜色
- 为了填满卡片增加说明性文案
- 让复制按钮比邮箱地址更抢眼

---

## Apple ID / 地区账号

### 分组

优先按地区聚合，同地区多个账号放进一个地区组。

### 视觉

- 地区色用于标题线、小圆点、地区标签、关联电话标签
- 账号本体仍以白色卡片承载
- 主用 / 订阅 / 历史角色通过字重和阴影再分级

### 不要

- 每个账号单独随机配色
- 只按国旗颜色高饱和上色
- 为了 Apple 感把所有地区差异抹掉

## 银行卡

### 分组

按资金用途，不按银行品牌：

1. 核心定存
2. 日常资金流
3. 低频备用
4. 小额虚拟

### 层级

- 核心定存：Level 1
- 普通常用一类卡：Level 2
- 二类 / 低频备用：Level 3

### 不要

- 工行红、建行蓝、农行绿地直接做品牌色卡片
- 所有卡同阴影
- 把完整卡号、复制按钮和用途标签挤在同一横排导致手机溢出

## 消费支出规划

### 分组

至少区分：

- 固定总额
- 虚拟消费
- 住房消费
- 账户用途分配
- 定存 / 预留
- 提醒 / 说明

### 视觉

颜色用于 summary（汇总）顶部线、section badge（分区标签）、圆点、amount pill（金额胶囊）、进度条、极淡边框。

不要整页使用旧式奶杏大渐变。

---

## 日常任务 / 年度计划

### 分组

- 日常任务按真实行为分类，例如学习、整理、创作、积累
- 今日重点与完成状态分开：重点表示今天最想推进的 1–3 项，勾选表示实际完成
- 年度计划默认折叠，展开后再按主题分组
- 历史记录按日期聚合，优先显示完成项、今日重点和三行记录

### 视觉

- 学习可用雾蓝，整理可用青灰绿，创作可用灰紫，积累可用暖沙金
- 分类 Section / group 以白色承载，颜色只放在顶部细线、圆点或勾选状态
- 今日概览和历史记录使用中性面板，不再叠加同一蓝色 wash
- 年度计划的父容器保持中性，各目标类别再使用自己的低饱和语义色

### 不要

- 所有任务分组、复选框、标签、年度卡片全部使用同一种蓝
- 用完成状态替代今日重点
- 为每条任务再套一层明显彩色卡片
- 历史记录默认全部展开造成页面过长

---

## 总档案馆

总入口只统一：

- 目录
- 页面骨架
- 返回逻辑
- Clear 气质

内部模块继承各自已确认的最新版视觉和数据。

禁止独立子页已经更新，但整合页仍保留旧副本。
